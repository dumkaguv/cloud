# Скриншоты ЛР3

Все изображения из этой папки вставлены в основной [отчёт](../readme.md). Снимки консоли AWS и страниц приложения сделаны вручную. Вывод команд записан в `../evidence/*.txt` и отрисован скриптом `../render-evidence.py`, например `py -3 render-evidence.py 12-health`. Личный IP на снимках замаскирован.
